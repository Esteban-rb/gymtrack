# GymTrack setup wizard UX redesign

## Objective
Make the Setup Wizard clear and guided: 4 visible steps, plain-language copy, consistent navigation, friendly validation, a skippable first run, and automatic Spanish UI on Spanish-language devices.

## Problem / why
The wizard built in T9 (see `odd/tasks/gymtrack-onboarding.md`) exposes implementation details: no step indicator, duplicated titles, errors shown on empty state, developer jargon ("parent flow", "draft handoff", "snapshot", raw UUIDs/enums/paths), buttons whose labels do not match their destination, dense editor forms, and decisions in the wrong place (cycle goal hidden in Review).

## Accepted user decisions (2026-10-09)
- UI stays English by default; when the browser/device language is Spanish (`navigator.language(s)` starting with `es`), the UI switches to Spanish automatically.
- Scope A–E in order (below), plus i18n.
- First run gets a "Skip for now" button guarded by an in-app confirmation: ES "¿Seguro que quieres continuar sin configurar tu rutina?" / EN "Are you sure you want to continue without setting up your routine?". This intentionally replaces the earlier rule "seed-only first-run users must finish reviewed configuration".

## Constraints (carried over, still binding)
- Keep tested domain logic: setup/schedule/draft validation, atomic reviewed apply, period reuse/archive, partial-session continue/restart, goals 4–8 (legacy 4/6/8 unchanged), medals/physiology unchanged.
- Import/preview must not persist before explicit acceptance; failed writes never produce false completion.
- Preserve real data; no Git commits/staging/repair/publishing (prior user instruction; repository index has missing blobs and no commits). Work-unit commits are therefore skipped and recorded as such.
- Engram mirror unavailable in this runtime: mirror **pending**.

## Acceptance criteria
- Each step shows "Step N of 4" and one title; Back/Next consistent everywhere.
- No empty-state error on first view of any step; no internal codes/paths/UUIDs/raw enums in UI.
- Spanish device → Spanish UI; otherwise English.
- First run can be skipped only after confirming the dialog; cancelling the dialog stays in the wizard.
- `npm test` and `npm run build` pass.
